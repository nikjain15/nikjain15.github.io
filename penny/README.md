# Penny

An AI-native money coach prototype: one thread, a visible specialist team, permission before every action. An illustrative concept on synthetic data. Not a product, and not financial advice.

Live at https://nikjain15.github.io/penny/. Source and design work: https://github.com/nikjain15/roleos-app/tree/main/labs/penny (pull request #154).

Free-text replies are scripted on this static site. Inside the Claude artifact version they are live, and a live reply is held and replaced by the scripted one if it names a product, uses guarantee language, or quotes a number the calculators did not produce.

This copy tracks `labs/penny/app/index.html` in that repo, wrapped in the document head above. It carries the corrections from the pre-demo audit in `labs/penny/AUDIT.md`.
