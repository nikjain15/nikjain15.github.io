# nikjain15.github.io

Personal website for Nik Jain, served via GitHub Pages.

## Project overview
A static single-page site. The content lives in `index.html`.

## Structure
- `index.html`: the full site (markup, styles, and content in one file).
- `CNAME`: custom domain configuration, if present.

## Setup and build
No build step. Open `index.html` locally in a browser to preview.

## Deploy
GitHub Pages publishes `main` automatically.

## Testing
No automated test suite. Verify visually across desktop and mobile widths before merging.

## Conventions
- House style: senior, precise, positive. Avoid em dashes and hyphen separators; prefer colons or commas.
- Keep figures and links accurate to the linked repositories.

## Commit and PR guidelines
- Edit `index.html`, open a PR to `main`, keep one concern per PR.
