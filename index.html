conduit · console
AI Platform · Infrastructure

Conduit Live ↗ Code ↗

The internal AI platform the four products are built on.
Every AI product re-solves the same plumbing: which model, how to ground it, how to stop a confidently wrong answer, what it costs. Conduit makes it one control plane, so a new use case is config, not a rebuild.
  • A new use case is a config object: one profile composes routing, retrieval, agents, prompts, guardrails, and evals; nothing redeploys
  • Model-agnostic: Anthropic, Cloudflare Workers-AI, and OpenRouter behind one interface, cheap open weights for bulk and a frontier tier for judgment
  • Quality as a gate: fail-closed evals inline, named metrics offline, and an MCP surface so any capability is pluggable
● open source · TypeScript monorepo · 10 packages · HTTP + MCP gateway · CI green
relay · advisor inbox
FinServ Compliance · Agentic Systems

Relay Live ↗ Code ↗

Relay reads the book, drafts and prepares; a person decides and sends.
A wealth manager's AI can flag twenty million client opportunities a year, but turning one into a documented, approved, client-facing action is the part nothing does.
  • Eighteen agents, eight mirroring real compliance desks (Reg BI, complaints, vulnerable-client protection), reading the whole book on a cadence and citing every claim
  • No outbound send path exists in the codebase: enforced by dependency-cruiser and a CSP that blocks it, not a permission the UI withholds
  • An eval harness that doesn't grade its own homework: expected outputs recomputed from raw CSVs, checked against hand-labeled data across 585 messages, in CI
● prototype · Next.js 15 · React 19 · TypeScript · 344 tests · 67 browser checks
clearline · quarter close
Fund Operations · Agentic Systems

Clearline Live ↗ Code ↗

Agentic fund operations for private markets: agents propose, named people release.
A private-markets quarter close runs on bank statements, call notices and ledgers that someone has to tie out line by line.
  • Four narrow agents: intake, matching, reconciliation and posting read the bank statement overnight and book only what the controller's policy allows
  • One write path: a draft journal a person releases into the ledger's own approval; no agent can pay, release or send
  • Deterministic engines, model at the edges: arithmetic, tolerances and posting are code; a model scores matches and phrases the trace
● demo · single HTML file · synthetic fund: 180 investors, 183 bank lines

Clearhouse Code ↗

A surety bond for agentic commerce: the merchant is underwritten before an agent pays.
Checkout protocols move the money, but neither answers whether an agent should trust a merchant nobody onboarded, or who pays when it shouldn't have.
  • One line to install: an MCP server any agent adds in one line; one tool returns a decision the agent can act on
  • Pays when its own score is wrong: a double-entry ledger, with claims and payouts underwritten in their own right
  • Top-3 finalist at Sundai Hack (MIT): Launch Lead; owned the contracts, underwriting engine, ledger and MCP server
● hackathon build · Next.js · TypeScript · 50 tests · eval over 70 labeled merchants

Team Collaboration

Rally Live ↗ Code ↗

Team chat that actually builds the team.
Slack and Discord move messages but don't build culture, and any points system is instantly gamed.
  • Peer-confirmed recognition, plus commitments that become GitHub issues (closed = kept)
  • Ungameable ledger: append-only, rank computed never stored; you can't confirm your own
  • The AI has no authority: it drafts, but never writes a points-bearing row
● live · Next.js 16 · Firestore · server-side AI

…and they talk to each other

Pulse and Rally aren't two silos: an agent in one can dispatch work directly to an agent in the other. Keyed by shared identity, they exchange recognition, progress, presence, and commitments. It's a working agent-to-agent dispatch mechanism across independent systems, the exact pattern enterprises face as every tool ships its own agent.
